# CPT316-Statement_Analyzer
This project implements a simple Statement Analyzer for the CPT316 coursework. It includes a lexer, parser, and parse tree visualization, supporting basic assignment statements of the form: <id> = <expr> ;
The analyzer checks lexical validity, parses input according to the grammar rules, reports syntax errors, and generates a parse tree.
